# AGENTS.md

Orientation for coding agents (and a quick reference for humans). Read
[CONTRIBUTING.md](CONTRIBUTING.md) and [SPEC.md](SPEC.md) too - this file does not
repeat them, it points at them and adds the things a machine tends to get wrong.

## The one rule that overrides everything: don't break the paper

The derivation scheme is frozen. A seed and phrase written on paper today must
produce the same passwords forever, on any machine. `core/tests/golden.rs` pins the
exact bytes. If a change makes those tests fail, it has broken every seed already
written down.

- Never touch derivation constants, domain-separation strings, byte order, or the
  KDF math in a way that changes output. KDF *parameters* (`M`, `T`) may grow; the
  *algorithm* may not.
- Entry id, alias domains, display label are metadata for matching and organizing.
  They must **never** feed into derivation. The password is a function of site,
  login, counter and policy - nothing else.
- A suspected flaw in the scheme is an issue to discuss, not a quiet PR.

## Build and test

```bash
cargo test --workspace              # crypto + storage + QR; run before AND after any change
cargo run -p svitok -- --help       # CLI, easiest way to poke the algorithm
cd app && npm install && npm run tauri dev   # desktop GUI (Tauri)
```

Toolchain is pinned: Rust `1.95.0` (`rust-toolchain.toml`), Node `22` (`.nvmrc`).
Don't bump these casually - reproducible builds depend on the pin
(see [docs/REPRODUCIBLE.md](docs/REPRODUCIBLE.md)).

## Lints

Workspace lints live in the root `Cargo.toml` (`[workspace.lints]`) plus `clippy.toml`.
They are set to `warn`, not `deny`, so they don't block an in-progress build; treat a
new warning in code you touched as something to fix, not ignore.

```bash
cargo fmt --all
cargo clippy --workspace --all-targets
cargo deny check        # advisories + licenses + duplicate versions (needs cargo-deny)
```

## Conventions a machine gets wrong here

- **`core/` is zero-dependency on purpose.** Do not add a dependency to it, ever.
  Elsewhere, add one only if it clearly earns its place.
- **Secrets stay in Rust.** The master key and seed never cross the JS/IPC bridge;
  only derived results and metadata do. Wipe key material with `svitok_core::wipe`
  when done.
- **Generated files:** `app/src-tauri/gen/schemas/acl-manifests.json` is regenerated by
  the Tauri build. If a build dirties it, revert it before committing - it is not a
  source change.
- **Don't hand-edit** other `gen/` output, `Cargo.lock` (except real dependency
  changes), or build logs.
- **Translations** are two flat dictionaries (`ru`, `en`) in `app/src/i18n.ts`.

## Commits and PRs

- Small, focused commits, imperative or present tense ("add X", "fix Y"). One logical
  change per PR. Match the surrounding style; see the Style section in CONTRIBUTING.md.
- If a PR touches the crypto core, say so up front and show the golden vectors pass.
- Security issues go to a private advisory, never a public issue.
